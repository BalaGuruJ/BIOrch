# Bootstrap Area

This area governs the initial setup tasks for the BIOrch project before formal architectural phases begin.

- Bootstrap tasks establish the project prerequisites.
- Architectural phases (e.g., Phase 2) define the core functionality.

## Execution Order
The execution order is strict:
00 Baseline -> 01 Git -> 02 Environment -> 03 Artifacts

## Governance
Each task requires:
1. Execution (creating a `RESPONSE_*.md` file)
2. Review (creating a `REVIEW_*.md` file)

A human checkpoint is required after Task 03 before initiating Phase 2.

These files are governance artifacts, not runtime code.
